🪄 LUMOS

Asistente de Azkaban Reads

📌 ¿Qué es LUMOS?

LUMOS es tu asistente virtual en Azkaban Reads. Con una narrativa oscura y adulta, LUMOS te ayuda a descubrir libros capturados, recibir recomendaciones personalizadas y solicitar títulos que aún no están disponibles.

Nota: El bot flotante 🪄 aparece en la esquina inferior derecha de esta página. Haz clic para iniciar una conversación.

🎯 Funcionalidades

  • 🔍 Búsqueda inteligente por título, autor o saga
  • ❤️ Recomendaciones personalizadas según tus gustos
  • 🧪 Test lector basado en tus 3 libros favoritos
  • 📩 Solicitud de libros no disponibles
  • 🔔 Notificaciones automáticas por correo electrónico

🔌 Integración en tu sitio

Para añadir LUMOS a cualquier página, solo añade este script:

<script src="/lumos-widget.js"></script>

O usa la API JavaScript para controlar LUMOS programáticamente:

// Abrir LUMOS LumosWidget.open(); // Cerrar LUMOS LumosWidget.close(); // Toggle (abrir/cerrar) LumosWidget.toggle();

📡 Endpoints de la API

LUMOS expone los siguientes endpoints REST:

GET /api/books/search?query=titulo - Buscar libros

GET /api/books/recommend?type=saga - Obtener recomendación

POST /api/books/test - Test lector con 3 libros favoritos

POST /api/requests/book - Solicitar un libro

POST /api/requests/notify - Suscribirse a notificaciones

POST /api/admin/add-book - Añadir libro (admin)

⚙️ Configuración

Para que LUMOS funcione correctamente, configura las siguientes variables de entorno:

EMAIL_USER=tu_correo@gmail.com EMAIL_PASS=contraseña_de_aplicacion SITE_URL=http://localhost:3000 PORT=3000

Importante: Para enviar correos con Gmail, necesitas generar una "Contraseña de aplicación" desde la configuración de seguridad de tu cuenta de Google.

🎨 Narrativa

LUMOS mantiene una narrativa oscura y adulta coherente:

  • Los libros están "capturados" y "encerrados"
  • El usuario es un "elegido" que puede "liberar" los libros
  • Tono serio, misterioso y sofisticado
  • Mensajes como: "Los libros permanecen capturados entre estos muros…"
